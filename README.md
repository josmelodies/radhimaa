# A Little Garden of Love 🌹

A responsive, single-page friendship surprise website made for Radhimaa.

## Files
- `index.html` — complete website (HTML, CSS, and JavaScript are included in this one file).

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

No Node.js, package installation, API keys, or build step are needed.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public address will appear on the Pages settings screen.

The website is static and does not collect or store visitor information.
